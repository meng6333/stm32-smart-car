# STM32 三合一蓝牙智能小车

基于 STM32F103C8T6（标准库）设计的两轮差速智能小车，支持蓝牙遥控、超声波避障、五路红外循迹与自动跟随。

## 功能
- 蓝牙遥控：USART1 连接 HC-05，串口中断接收指令字符，切换前进/后退/转向/原地旋转与加减速。
- 自动避障：HC-SR04 测距 + SG90 舵机左右扫描，低于阈值停车蜂鸣报警并绕行。
- 循迹：五路红外传感器采集黑线位置，区分直行/小弯/大弯/丢失修正。
- 自动跟随：以超声波距离为依据，近距后退、远距前进，滞回区间保持距离。
- 0.96 OLED 实时显示运动状态与测距结果。

## 目录
- User：主程序与中断服务
- Hardware：电机、串口、超声波、舵机、循迹、OLED、蜂鸣器等驱动
- System：延时等系统模块
- Library：STM32 标准库外设驱动
- Start：启动文件与内核支持
- Firmware：编译生成的 HEX 固件

## 开发环境
Keil MDK、STM32F103C8T6、C 语言标准库；PCB 嘉立创打样，自主焊接组装与烧录调试。
